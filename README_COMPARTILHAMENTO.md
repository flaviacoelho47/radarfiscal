# Compartilhamento de notícias

Cada card de notícia agora possui:

- **WhatsApp**: abre o compartilhamento com título, fonte e URL original.
- **Copiar link**: copia a URL original da matéria para a área de transferência.
- Contingência para navegadores sem suporte à Clipboard API.

Os botões compartilham sempre a matéria original, não a URL interna do Radar Fiscal.
