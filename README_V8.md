# Radar Fiscal V8 Final

## Ajustes finais

- Newsletter reduzida e mais proporcional.
- Removido o botão **Acessar portal** dos cards de fontes.
- Mantida somente a ação **Principais notícias**.
- Coletor reforçado para limpar HTML, entidades numéricas, atributos e fragmentos de código.
- Fontes HTML agora tentam usar `description`, `og:description` ou `twitter:description` da matéria original.
- RSS do Portal Contábeis continua prioritário.
- Botões **Ler notícia**, **WhatsApp** e **Copiar link** centralizados vertical e horizontalmente.
- Trechos limitados visualmente para preservar o layout.

Envie todo o conteúdo para a raiz do repositório e execute o workflow manualmente para regenerar `docs/data/noticias.json` com as prévias limpas.
